### 2. TOOL FUNCTIONALITY SPECIFICATIONS

#### Tool 1: Robots.txt Generator (`robots-txt-generator.html`)
- UI CONTROLS:
  * Global Access Dropdown: Allow All Bots, Block All Bots.
  * AI Crawler Toggles: Toggles for GPTBot, ClaudeBot, Bytespider, CCBot, PerplexityBot.
  * Search Engine Toggles: Google, Bing, Yandex, Baidu.
  * Delay Setting: Default (None), 5s, 10s, 20s.
  * Subfolder Exclusion Input: Text field to add paths to disallow (e.g., `/admin/`, `/private/`, `/cgi-bin/`).
  * Sitemap URL Input: Optional input field to declare `Sitemap: https://...`.
- OUTPUT: Live generated syntax in a dark code block with a "Copy File" and "Download robots.txt" button.

#### Tool 2: Static Site XML Sitemap Builder (`xml-sitemap-builder.html`)
- UI CONTROLS:
  * Main Textarea: Paste multiple full site URLs (one per line).
  * Default Priority Dropdown: `1.0 (Homepage)`, `0.8 (Important Pages)`, `0.5 (Standard Pages)`.
  * Change Frequency Dropdown: `always`, `hourly`, `daily`, `weekly`, `monthly`, `yearly`, `never`.
  * Include Last Modified Date Toggle: Inserts `<lastmod>YYYY-MM-DD</lastmod>` using today's ISO date.
- OUTPUT: Real-time formatted XML structure inside a syntax-highlighted block with a "Copy XML" button and "Download sitemap.xml" button.

#### Tool 3: Meta Title & Description Pixel Checker (`meta-pixel-checker.html`)
- UI CONTROLS:
  * Title Input (Text field) + Real-time character count AND calculated pixel width (Desktop target: max 600px / ~60 chars).
  * Description Input (Textarea) + Real-time character count AND calculated pixel width (Desktop target: max 960px / ~155 chars).
  * URL Input (Optional string for preview URL display).
- OUTPUT & VISUAL PREVIEW:
  * Dynamic Google SERP Snippet Box: Renders blue clickable title, green/gray URL breadcrumb, and snippet text.
  * Truncation Warning System: Red/Yellow warning badge if title exceeds 600px or description exceeds 960px, showing exactly where Google will append `...`.
