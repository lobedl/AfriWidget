---
name: New page SEO checklist
description: Durable SEO requirements for new AfriWidget static tool pages
---

Every new indexed tool page must be audited as served HTML, not only by inspecting source patterns. Check title and description lengths, one canonical URL, matching Open Graph URL, Twitter tags, two JSON-LD blocks, one H1, 800+ visible raw body words, crawlable raw navigation links, sitemap and robots coverage, no noindex or redirects, and the required scroll-to-top snippet.

**Why:** Static pages can appear complete while missing a small rule that affects crawlability or AdSense eligibility, especially when shared navigation is injected by JavaScript or long-form text is just below the word threshold.

**How to apply:** Run a focused per-page audit after creating or editing a tool, then restart the static workflow and verify every clean route returns HTTP 200.
