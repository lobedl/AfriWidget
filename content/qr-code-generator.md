## About the QR Code Generator

A QR code is a compact visual way to carry information that a phone camera can read. AfriWidget’s QR Code Generator is designed for practical everyday use: create a code for a website address, a short message, or a wireless network. The code is drawn in your browser, so the text you enter is not sent to AfriWidget’s servers. That makes the tool useful for menus, event signs, classroom handouts, product packaging, guest Wi-Fi cards, and quick links shared in communities with a mixture of smartphones.

The generator supports three formats. URL mode is best when you want a camera scan to open a website. Plain-text mode can hold an instruction, contact note, reference number, or short announcement. Wi-Fi mode follows the common Wi-Fi QR convention, including the network name, security type, and password. A receiving phone may show a “join network” action when it recognises that format. The exact experience depends on the phone’s operating system and camera application.

## How to use it

1. Choose URL, plain text, or Wi-Fi from the format selector.
2. Enter the information carefully. For Wi-Fi, check the network name, security setting, and password character by character.
3. Watch the canvas preview update as you type. A successful preview means the browser created an image from the current value.
4. Test the code with at least two phones or scanning apps before printing a large batch.
5. Select Download PNG to save an image that can be placed in a document or sent to a printer.

Shorter data generally produces a simpler code with larger, easier-to-read modules. A very long paragraph or a long tracking URL creates a denser symbol. Dense symbols can still work, but they need more physical size, stronger contrast, and a clean surface. If you are designing a poster, leave a quiet white margin around the code. Do not place text, logos, or decorative lines inside that margin because scanners use it to locate the symbol.

## Practical design and accessibility guidance

Use dark modules on a light background and avoid transparent backgrounds. A QR code is not a substitute for visible information: include a readable URL or a short instruction beside it so people know what they are about to scan. Add a clear call to action such as “Scan to view the menu” or “Scan to join guest Wi-Fi.” For public signs, provide a non-QR alternative for people who cannot use a camera, including a typed web address or a staff contact.

Always test the printed version at the final viewing distance. A code that works on a laptop screen may fail on a glossy poster, a folded leaflet, or a low-resolution photocopy. Check glare, shadows, cropping, and whether the code has been stretched unevenly. PNG is convenient for normal documents, but a professional print workflow may require a vector version generated by a design application.

Wi-Fi codes deserve additional care. Anyone who can scan the code may receive the network credentials, so use a guest network rather than exposing a private administration network. Change the password when the event, rental, classroom term, or temporary access period ends. QR codes cannot make a weak password strong, and they cannot revoke access after an image has been photographed.

## Privacy and browser processing

This tool performs its main work in the browser. The entered value is used to generate the canvas image and is not stored in an AfriWidget account because no account is required. Browser extensions, screenshots, clipboard tools, analytics, or third-party scanning applications may have their own data practices, so treat the final image as public if you place it on a public sign. Do not encode private medical, financial, or identity information unless every person who can scan it is authorised to see that information.

## Frequently asked questions

### Can I create a QR code for a website?

Yes. Choose URL, paste the complete address including `https://`, and verify the preview. Test the final link on a phone before sharing it.

### Does the QR code expire?

The image itself does not expire. A URL can stop working, a Wi-Fi password can change, or a service can be removed, so the destination still needs maintenance.

### Why will a very long message not render?

QR symbols have capacity limits. Try a shorter message or place the full content on a webpage and encode that shorter URL instead.

### Is the downloaded PNG private?

The browser creates the PNG locally. After download, protect the file like any other document, especially when it contains a Wi-Fi password or private text.

### Can every camera scan it?

Most current phones can scan standard QR symbols, but lighting, distance, camera software, and print quality affect results. Always test the actual output.
